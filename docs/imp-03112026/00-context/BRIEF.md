## Honest notes (read these; they are why some defaults differ from a literal reading)
1. **The keys never go inside the app.** An APK or web bundle can be unpacked by anyone; a key in `EXPO_PUBLIC_*` is a published key. The keys live only as **Supabase secrets of the Edge Functions** (like SGC). The app holds the same public anon key it holds today. `tools/check-bundle-env.mjs` gets a second check (no `sk-ant-`, no `AIza`, no `AZURE` in a bundle) and a `.gitleaks.toml` is added (csd-app has one).
2. **Reusing the company's key means the company pays for Car Guy and for his friends' usage.** He decided; so: per-user hourly limit, per-user daily cost cap, global daily cost cap and a **kill switch**, all in `app_config` and editable in Admin → Uso y costos (extended); every call logged in `ai_usage` with cost. The code reads the key by one env name, so moving Car Guy to its own key later is one `secrets set`, zero code. Recommendation (not a blocker): create a second key in the same Anthropic workspace named for Car Guy so spend is separable.
3. **Not everything SGC holds is reusable.** Inventory in SPEC-A: reusable = Anthropic, Google Maps *server* key, Azure Speech (and `STT_API_KEY` if it exists in SGC's Supabase secrets). **Never** copied: `csd-core` Supabase keys (prod/dev, anon/service/db password), Google service-account JSON + delegated Workspace user, WhatsApp tokens, `AGENTE_ESCRIBA_GITHUB_TOKEN`, Vercel OIDC, QA/store-review credentials, `*_SYNC_SECRET`, VAPID. Reason: they are the company's data or identity, not "API keys for services".
4. **Google Maps terms.** Car Guy draws maps with MapLibre/MapTiler. Google's Maps Platform terms restrict using Google data (Places, Geocoding, Directions, Roads) with a non-Google map, and SGC's own map docs went all-Google for that reason. So Google is used **server-side only, for list/text features with attribution, never drawn on MapLibre** (SPEC-G §Places). PROMPT-00 re-reads the current Service Specific Terms and records the verdict in ADR-69; if the terms forbid it even for lists, the flag `FEATURE_GOOGLE_PLACES` stays off and the report says so — nothing waits.
5. **Local-first vs AI.** AI needs an account (for the JWT, limits and consent) and a connection. Offline or signed-out: AI buttons explain why and the manual form is untouched. Nothing about the app's offline promise (ADR-05) changes.
6. **Privacy.** A matrícula/seguro photo carries cédula, name and address. Photos are sent, read and discarded (never stored by the function, never logged), only the fields asked for come back, consent is explicit and verified server-side, and a data-and-third-parties doc is written for Car Guy (Anthropic, Azure, Google). Play Store is not in scope (his choice) but the doc is ready for when it is.
7. **Voice** needs the microphone: `vercel.json` currently sends `Permissions-Policy: microphone=()` (blocks it on web) and the native recorder is a new native module → **2.7.0 ships as an APK**, not an OTA (fingerprint changes). The permission goes through the ADR-59 registry.
8. **I exposed the two key files in the session that produced this package** (the listing printed them). Rotating both is recommended (checklist item) and does not block anything: the code never changes when a key rotates.
