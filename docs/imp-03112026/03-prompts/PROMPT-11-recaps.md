## Steps
1. **Inventory the data** each card needs and the query that provides it (SPEC-J §J2–J3); write `docs/imp-03112026/recap-data-map.md`. Anything missing becomes an aggregate query in `statsQueries.ts` (SQL aggregation, not JS loops; a year must build < 300 ms on a mid phone).
2. **`lib/domain/recap.ts`**: `buildRecap({ period, scope })` → typed `Recap { cards[] }` (discriminated union per card kind, each with the numbers and a `copyKey` + params for i18n). Pure, no React. Rules: skip cards without data, never a "0 km" card, comparisons only when the previous period has data, efficiency only from full-to-full pairs, local-time boundaries, vehicle scope (active/all/one). Tests: empty, thin, normal, multi-vehicle, DST, year boundary; **cross-check test** that card totals equal the Cifras/trip-detail totals for the same period.
3. **Viewer** `app/resumen/[period].tsx` + `components/recap/*`: story cards per SPEC-J §J4 (tap/swipe/hold, progress segments, 6 s auto-advance unless reduced motion, count-up numbers once), a11y groups with full sentences, motion tokens only (`transform`/`opacity`), JDM palette, SVG icons, photo background only with contrast overlay. Desktop layout: centred 9:16 card + keyboard + side list.
4. **Cards**: implement every card in SPEC-J (cover, distance/time, speed, fuel, cost, care, build, streaks/firsts, compare, closer; yearly adds month bars, cost of ownership, maintenance story, places (J6), odometer start→end, garage card for multi-vehicle, year-in-one-image). Month bars are tappable → that month's recap.
5. **Share** (SPEC-J §J5): export the *same* card components at 1080×1920 and 1080×1350. Native via `react-native-view-shot` (verify Expo 57 compatibility; add only if absent), web via the canvas/`html-to-image` path already used elsewhere (reuse before adding a dependency; if a new package is needed record it in Decisions and `DATA-AND-THIRD-PARTIES` is unaffected — nothing leaves the device). Share sheet with toggles "Mostrar gastos" (default off), "Mostrar nombre del carro", "Mostrar mi nombre" (default off). **Never** plate, VIN, absolute odometer, exact places, home/work, other people's names — enforce in the *share model* (a `toShareModel(recap, options)` that drops fields) and test it by asserting absence. Optional yearly PDF via the Libro path if it costs < half a day; else record "not done".
6. **Entry points**: Hoy "Siguiente paso" card when a recap closes (coordinate with SPEC-K's `nextStep()` — if PROMPT-12 has not landed yet, expose `recapReady()` and add the card there later; record which), Cifras → **Resúmenes** list (months/years with data), vehicle ficha → Resumen, deep links `/resumen/2026-10` and `/resumen/2026`. Local notifications on the 1st (09:00 local) for the closed month and on 1 Jan for the year, toggle in Ajustes → Notificaciones ("Resúmenes"), scheduled/cancelled with the permission registry's notification state.
7. **Places card** (J6): area-level only, home/work excluded from sharing, omitted if trips are off; use the thin-line route layer when no labels are available.
8. i18n es/en (plurals, number/currency formats), a11y checks (focus, labels, contrast in light/dark), reduced-motion path. Playwright: open a recap from fixtures, advance with keyboard, screenshot the exported card (before/after privacy toggles) into `04-tracking/screens/`. Typecheck/lint/tests/web build green. Commit.
